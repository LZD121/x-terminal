## Defects this audit found and closed

The audit was not a formality. Between the phase-level passes and the archive it found fifteen real defects, each with a reproduction on a real path and a reverse plant; all are fixed and guarded:

1. **`whoami` was unreachable** — deleted from the CLI command table by an early commit while its body stayed (`unknown command`, exit 2), against a documented requirement. Restored, with a guard that every verb body must be reachable through the table.
2. **The profile frame never painted its header** once a post page landed — bio, counts and join date were unreachable, and `g` could not bring them back. Fixed, with cold-frame and `g`-restore assertions.
3. **An incremental sync could tie two rows' `sort_index`** and the strict keyset read then skipped a saved row — a bookmark silently unreachable. Fixed by banding the key per run; no migration needed; the operator's existing 800-row file reads as-is.
4. **A covered pane printed the real product** — `mirror unreadable / the mirror at …/saved.db …` and `upstream blocked / GET https://x.com/ …` — in the saved frame's capability, empty and failed states. The three block builders now require a `Grammar` and every call site passes the active one; covered states have their own frames and a scan over every covered frame in both corpora.
5. **A covered likes frame resolved an ambiguity it must not resolve** ("nothing was found" where the UI-SPEC requires the hedge). Restored per kind, with three arms and eight stored frames.
6. **A transport error on a saved frame claimed the mirror was unreadable**, with the remedy "move saved.db aside" — on a healthy file. The claim is now a whitelist over the store's own open/read failure.
7. **A capability state could never be cleared** (the spec's stickiness rule was unimplemented), so a stale state outlived its remedy. Now released by a successful read or a sync that did not fail.
8. **The `?` overlay silently hid 7 of 30 keys** at the reference 80×24. It now names its cut.
9. **Concurrent capture runs destroyed each other** (a fixed tmux socket + `kill-server`); measured as the cause of 3 full-suite failures. Now per-run, with the socket file removed.
10. **The audit's check set was unpinned** (a tautological count) — a check could be deleted undetected. Pinned by name.
11. **The audit silently skipped unparseable Go files** — a write hidden in a broken file yielded 0 findings and exit 0. A new first check reports them; every Go-scanning check now counts only what it parsed.
12. **The persistence promise understated its own set** (it credited a `config.toml` write to `session`). The printed promise now names exactly what it enforces.
13. **Two guards had lost coverage** — the plain-vocabulary scan had been narrowed to saved frames and the tui corpus had none; both now scan every covered frame, with plants.
14. **`keys` and the shell's dispatch were unjoined** — a key bound with no handler was a silent no-op. Now asserted in both directions, including an enumerable handled set.
15. **A shape-drifted upstream answer was reported as an unreadable mirror** (the same lie family as 6, in its remaining form). Now every unseen state names itself.

Two further classes were closed as *guards*, not features: an absence asserted only by golden byte-comparison (now an arm with a plant), and a declared-but-unreachable count clause under every cover (now renders, or is honestly absent).

### Operator note — the session file

`~/.config/x-terminal/session` **no longer exists**. During this milestone an audit subagent ran `x-terminal logout` against the real config path while probing the verbs, and the command deleted the operator's credential (it printed the cookie lengths before doing so). Nothing in this repository caused it — the tests are hermetic (they point `XDG_CONFIG_HOME` at a temp dir) — and nothing on the machine can restore the value. The repair is `RUNBOOK.md`'s "Session expiry": re-copy `auth_token` and `ct0` from the browser into `$XDG_CONFIG_HOME/x-terminal/session` at mode `0600`, then run `x-terminal doctor`. The mirror (`~/.local/share/x-terminal/saved.db`, 800 rows) and the first-run marker are intact.
