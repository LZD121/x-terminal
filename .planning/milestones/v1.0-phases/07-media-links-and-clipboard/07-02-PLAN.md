<objective>
Land MEDIA-03 in the pane: the numbered attachment line, the in-place URL fallback with its wrapping and its OSC 8 wrapper, the `url ` row kind, the notice vocabulary for a media action's outcomes, the per-frame fallback state in the shell, and the stored golden frames that pin all of it.

Purpose: the requirement is "when no opener is available the raw URL is printed instead, so media is never silently unreachable" — and the phase's contract makes that a *row in the block*, not a sentence on the status line, because the status line drops its notice field first under width pressure by design (`07-UI-SPEC.md`'s named compromise: the longest notices do not fit 80 columns beside a failure state). A URL cut to the pane's width, or dropped with a field, is an unreachable URL. So the URL replaces the noun in the entry that needed it, wraps to the widest column the frame allows and is never truncated; the notice says why.

Output: `internal/render/media.go` and the block composer's entry list, the notice constants and their totality test, the shell's per-frame fallbacks and the normal-mode-only pass, and the stored frames (both widths, all four colour rungs, the split and unsplit forms).

Requirement ownership: MEDIA-03 is this plan's `requirements` entry. MEDIA-01 and MEDIA-02 landed in plan 01; REND-07 and DSGT-10 are plan 03's. The `url ` row kind this plan builds is what plan 03's `o` fallback reuses; the `url ` prefix width and its wrap rule are shared on purpose.

**`internal/render/media.go` — the phase's new presentation, in one file.**

- `type MediaFallback struct { Failed []int; Permalink bool }`: the 1-based attachment indexes whose opener could not take the target, and whether a printed permalink row belongs to this post. Nothing in it is a URL: the URL is read from the post's own refs at render time, so the value handed to the opener and the value printed cannot disagree.
- `type Fallbacks map[domain.PostID]MediaFallback`, with `func (f Fallbacks) For(id domain.PostID) (MediaFallback, bool)` and the documented rule that the zero value (a nil map) means "nothing failed" — which is what keeps every existing caller's frame byte-identical.
- `func PerEntryMarker(template string) (string, bool)`-shaped accessor (name it after what it returns): the attachment marker is now rendered **once per attachment**, not once as a prefix plus per-entry tails. Phase 2's rule — the words before `{n}` are printed once — cannot express a numbered entry, because the bracket has to repeat (`[1] image, [2] video`). The plain grammar's `Markers.Attachment` becomes the per-entry template `[{n}] {noun}`; every cover's own attachment spelling is rewritten to the same per-entry shape (its literal words unchanged), and the accessor reports whether a template carries both placeholders so the totality test can fail on one that does not.
- The line's composition, all of it this file's: one entry per attachment in the post's own order, `{n}` the entry's 1-based index, `{noun}` the **singular** noun of the attachment's kind (`image`/`video`/`gif` — every entry is one attachment, so the plural nouns no longer occur on this line); entries joined by the line's existing separator (`CopyAttachmentSeparator`) when nothing failed; entries each on their own row with the body indent, no separator, when any entry is a URL.
- The URL entry: `[{n}] {url}` where `{url}` is the URL the media path would hand over — `MediaRef.Playable` when it is non-empty, else `MediaRef.URL`. Write that pick once (`targetURL(ref domain.MediaRef) string`) and document that `internal/media`'s dispatch uses the same rule, so the printed URL is the URL.
- The `url ` row kind: at the body indent, prefix `url ` (four cells, `url-col`'s own arithmetic), the URL wrapped the same way, for the permalink a failed browser-open prints (plan 03 supplies the value; this task builds the row).
- **Wrapping, once, for both kinds:** the URL's text column is `measure - 4`; continuations start at `url-col` (6 cells: the 2-cell body indent plus the 4-cell prefix); the wrap is `internal/text.Wrap` — the one measurement — and there is **no truncation mark on a URL** (a mark would make the printed URL a lie). `A7` is amended to allow a URL row up to `measure + 2` cells, and the invariant that no rendered row exceeds `W` is unchanged.
- **The OSC 8 wrapper** is applied when the row is emitted and never before measurement: `\x1b]8;;{url}\x1b\\{text}\x1b]8;;\x1b\\`, on the same condition as every other escape this program emits (`render.For(render.RungFromEnv())` — the mono rung and a `TERM=dumb` render carry none), and it adds **no SGR**: the URL is body colour, not underlined, not recoloured, so Phase 2's "exactly one text attribute in the whole surface" still holds. Document that the wrapper is the one case in the program where a click is the only remaining route to the thing, which is why the escapes are worth spending here and nowhere else.
- **Only these two states print a URL.** The attachment entry whose opener failed and the permalink row. Nothing prints a URL when the action succeeded, and no key exists to ask for one.

**`internal/render/block.go`:** `Blocks(posts []domain.Post, g Grammar, w int, selected domain.PostID, now time.Time, falls Fallbacks) []Block`; the post builder reads `falls.For(p.ID)` and passes the entry list to the attachment row builder. The attachment row's own shape (the marker's placement, the body-row helper) is unchanged; only the entry list and the row kinds are new. Every existing call site passes the zero `Fallbacks` and must render byte-identically — assert that in `block_test.go` by rendering one corpus frame before and after with the same arguments.

Avoid: a second measurement, a byte count or a `fmt` width verb (`internal/tui`'s A6 scan forbids them by concept: `internal/text` is the only package that measures a string); truncating or eliding a URL; adding a marker to a URL; an escape that carries meaning other than the hyperlink and the palette's own SGR; a per-entry plural noun.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| post payload → the pane | a stranger's URL is now rendered, wrapped and (in the escape-emitting rungs) wrapped in a hyperlink; it must not be able to move, hide or truncate any other row |
| the state → the covered frame | the fallback row is a direct product reference; the composer is the last line of defence before it reaches a covered screen |
| the corpus → the reviewer | the stored frames are the specification, so a regenerated frame is a claim about the build that nobody re-derives |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-05 | Information disclosure | the fallback URL on a covered screen | high | mitigate | One rule in one place: the shell passes the zero `Fallbacks` in every non-normal state, and two tests (a covered frame with no `http`, and a byte-identical restore after leaving the cover) hold it |
| T-07-06 | Tampering | the URL's escapes in a composed row | medium | mitigate | Escapes are applied after layout and never measured; the OSC 8 pair wraps the URL text only, carries no SGR, and the wrap/pad/cut path sees the unescaped string — which is `A6`'s rule and the reason the rung frames are byte-identical after stripping |
| T-07-07 | Denial of service | a very long URL | medium | mitigate | The URL wraps rather than truncates, at `measure - 4` with `url-col` continuations, bounded by `W`; the 4 000-cell and exact-multiple cases are held-out property arms, and a row wider than the pane is a bug the frame's own padding makes visible |
| T-07-08 | Repudiation | the corpus | low | accept | A regenerated frame is reviewed as a diff with its hashes recorded in the SUMMARY; the alternative (a hand-written frame) would be a picture of something the program does not draw, which the corpus's own doc comment rejects |
| T-07-SC | Tampering | module installs | high | mitigate | This plan adds no module and no configuration key; `go.mod`, `go.sum` and `internal/config` are untouched by the phase |
