Implement `internal/session`:

- `type Secret string` with `String() string`, `GoString() string` and `MarshalJSON() ([]byte, error)`
  all returning the literal `<redacted>`; also implement `MarshalText` and
  `func (s Secret) LogValue() slog.Value` returning `slog.StringValue("<redacted>")`. The raw
  value is reachable only through an explicitly named method, e.g. `func (s Secret) Reveal() string`.
- `type Session struct { AuthToken Secret; CTO string; Source string }` — note `CTO` is NOT
  secret (it is the CSRF token and appears in request headers by design), but it must still not
  be logged in a `%+v` dump; give it the same treatment for safety.
- `func Load(path string) (Session, error)`:
  - `os.Lstat` first: if the path is a symlink, refuse with `session file is a symlink: <path>`.
  - mode check: `perm & 0077 != 0` → refuse with a message that includes the exact fix command
    `chmod 600 <path>`.
  - parse `KEY=VALUE` lines, ignoring blank lines and `#` comments; accept keys `auth_token`,
    `ct0` case-insensitively; an unknown key is a warning.
  - environment override: `X_TERMINAL_AUTH_TOKEN` and `X_TERMINAL_CT0` replace the file values
    when non-empty; a file is then not required at all.
  - missing file with both env values set is OK; missing file with neither is a typed
    `ErrNoSession` whose message tells the user where to put it and that the values are session
    cookies that disappear when the browser closes.
- `func (s Session) Valid() bool` and `func (s Session) Summary() string` returning something
  like `session: present (auth_token 40 bytes, ct0 160 bytes, source /path)` — lengths only, never
  values.

`session_test.go` covers: mode 0600 accepted; 0644 refused with `chmod 600` in the message;
symlink refused; env override wins; missing file without env gives `ErrNoSession`; unknown key
warns.

`leak_test.go` MUST assert the redaction contract by capturing output, not by inspection:
marshal a `Session` through `encoding/json`, `fmt.Sprintf("%v")`, `fmt.Sprintf("%+v")`,
`fmt.Sprintf("%#v")`, `slog` via a buffer, and `errors.Join`, concatenate everything, and assert
the fixture cookie value appears nowhere while `<redacted>` does appear at least once. Give this
test an anti-vacuity arm: assert the concatenated buffer is non-empty and that the fixture value
is a needle that WOULD be found if redaction were removed — e.g. also assert that
`s.Reveal()` does contain it, proving the needle and the haystack are the ones under test.
  </action>
