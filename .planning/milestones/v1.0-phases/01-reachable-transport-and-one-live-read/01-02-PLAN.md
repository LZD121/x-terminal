<objective>
Make the network path real and honest: one proxied transport, one request choke point, one
classifier, and a `doctor` that names exactly which link is broken.

Purpose: the project's dominant failure mode is silent wrongness — an unreachable upstream or a
stale operation id rendering as "no posts". This plan builds the machinery that tells those
apart, and the choke point every later request must pass through.
Output: `x-terminal doctor` reporting five distinct connectivity outcomes, plus the transport,
classifier and limiter that the GraphQL layer will use.
</objective>

`internal/xweb/proxy.go`: `func NewTransport(cfg config.Config) (*http.Transport, error)`.
Build one `http.Transport` whose `Proxy` func returns the configured proxy URL, or nil for a
direct dial. Support both `http`/`https` and `socks5`/`socks5h` schemes — `http.Transport`
already understands `socks5` URLs, so parse and pass through rather than implementing a dialer.
When `NO_PROXY` is set, pass it to `httpproxy.FromEnvironment`-equivalent handling or leave the
env-based `ProxyFromEnvironment` in place as the fallback path. Set a dial timeout (10s), TLS
handshake timeout (10s) and `ForceAttemptHTTP2 = true`.

`internal/xweb/transport.go`: a small client wrapper carrying the resolved proxy plus the
upstream base URLs as constants (`https://x.com`, `https://api.x.com`). Provide
`func (c *Client) Do(ctx context.Context, req *http.Request) (*http.Response, error)` that
routes every request through the limiter.

`internal/xweb/limiter.go`:
- `type Limiter struct` with an injectable clock (`now func() time.Time`) and sleep function so
  tests need no real time.
- `func (l *Limiter) Do(ctx context.Context, fn func() (*http.Response, error)) (*http.Response, error)`
  enforcing: **single-flight** (a second concurrent call waits for the first to finish, it does
  not fail), an **inter-request floor of 1.5s**, and a **session cap of 200 requests** returning a
  typed `ErrRequestCap` when exceeded.
- `func (l *Limiter) Budget() (used int, limited int, reset time.Time)` for the doctor line.

`limiter_test.go` covers: two sequential calls are at least the floor apart (fake clock); a
concurrent second call blocks rather than erroring; the cap trips at exactly 200 and not at 199;
a `429` response increments the limited counter.

<task type="auto">
  <name>Task 2: The measured classifier</name>
  <files>internal/xweb/classify.go, internal/xweb/classify_test.go</files>
  <read_first>.planning/research/UPSTREAM-PROBE.md</read_first>
  <action>
Implement `func Classify(status int, headers http.Header, body []byte) Outcome` where
`Outcome` is a typed string enumeration with an `Error() string` and a `Remedy() string`:

| Outcome | Trigger (measured on 2026-10-14) | Remedy text must say |
|---|---|---|
| `OutcomeAuthRejected` | `401` | session missing/expired — re-copy the cookie |
| `OutcomeSignerOrAuth` | `403` with zero-length body | auth headers unsupported or the transaction-id is required for this operation |
| `OutcomeUnknownOperation` | `404` with zero-length body | the operation id is stale or unknown — refresh the registry or pin it |
| `OutcomeEndpointRetired` | `404` with a JSON body | this endpoint is retired — do not retry |
| `OutcomeRateLimited` | `429` | wait until the reset time from `x-rate-limit-reset` |
| `OutcomeSoftBan` | `200` carrying `errors[].code == 88` while `x-rate-limit-remaining > 0` | stop for the session |
| `OutcomeLoadShed` | `5xx` or `200` carrying a load-shed error | bounded backoff, distinct from rate limiting |
| `OutcomeUnauthorized` | anything else with `errors[]` | print the API's own message |

Two rules that must be visible in the code and asserted in tests:
1. **An empty body is never `OutcomeEmpty`-as-success.** There is no outcome meaning "no posts".
2. `Classify` never returns an outcome whose remedy is "retry" for `429`.

`classify_test.go` must include a table built from the *measured* shapes: `403`/0 bytes,
`404`/0 bytes, `404` with `{"errors":[{"message":"Sorry, that page does not exist"}]}`, `429`,
and a `200` body with `errors[].code = 88`.
  </action>
  <verify>`go test ./internal/xweb/... -run Classify -v`</verify>
  <acceptance_criteria>
    - every row of the table above has at least one test case
    - a test asserts `403` with 0 bytes and `404` with 0 bytes produce *different* outcomes
    - a test asserts a 0-byte body never yields a success outcome
  </acceptance_criteria>
  <done>Classifier keyed on the measured shapes, with the empty-body rule enforced by test.</done>
</task>

<task type="auto">
  <name>Task 3: Connectivity self-check and the doctor subcommand</name>
  <files>internal/netcheck/netcheck.go, internal/netcheck/netcheck_test.go, internal/cli/doctor.go</files>
  <read_first>.planning/research/UPSTREAM-PROBE.md</read_first>
  <action>
`internal/netcheck`: `type Result struct { Outcome Outcome; Detail string; Elapsed time.Duration }`
and `func Check(ctx context.Context, cfg config.Config, sess session.Session) []Result`, running
these stages in order and stopping at the first that fails:

1. **route** — DNS resolution of `x.com` plus a TCP connect. Failure → `no route to x.com`.
2. **proxy** — if a proxy is configured, connect to the proxy's host:port. Refused/timeout →
   `proxy refused`. (This must be distinguishable from stage 3.)
3. **upstream** — TLS handshake + `GET https://x.com/` expecting 2xx/3xx. A Cloudflare challenge
   (status 403/503 with `cf-mitigated` or an HTML body containing `cf-` markers) →
   `TLS/Cloudflare challenge`; a timeout after a successful proxy connect → `proxy reached but
   upstream blocked`.
4. **session** — only when a session is present: one authenticated API call
   (`/1.1/account/settings.json` or any endpoint the plan-03 registry exposes) expecting 200 →
   `authenticated read OK`; classify anything else through `xweb.Classify`.

Stage 4 must be skipped, not failed, when no session is configured — and the result must say so.

`netcheck_test.go` must drive all five outcomes with an injected `*http.Client` built on an
`httptest.Server` (never the real network), and must include an anti-vacuity test: a successful
run returns exactly `authenticated read OK` and its `Elapsed` is non-zero.

`internal/cli/doctor.go`: replace the stub. Print one line per check plus a final line from
`Limiter.Budget()`: `requests: N used, M limited, cap 200`. Print the session summary from
`session.Summary()` (lengths and path only). Exit non-zero if any check failed, 0 if all passed.
Support `doctor --json` emitting the same data as JSON. Also accept `doctor --pin <operation>
<queryId>` and `doctor --refresh-ids` as recognised flags that print `not implemented yet` for
now — plan 03 wires them.

  <verify>`go test ./internal/netcheck/...` and then, live: `go run ./cmd/x-terminal doctor` with the proxy up (expect exit 0) and with `X_TERMINAL_PROXY=http://127.0.0.1:9 doctor` (expect `proxy refused`, non-zero exit)</verify>
  <acceptance_criteria>

    - `doctor --json` output parses as JSON and contains no value longer than 200 characters that
