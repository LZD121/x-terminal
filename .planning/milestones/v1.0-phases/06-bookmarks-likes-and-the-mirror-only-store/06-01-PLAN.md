`internal/store/schema.go` — the file's own shape:
- `type Store struct { path string; w *sql.DB; r *sql.DB }` with neither handle exported (a caller that could reach one could skip a pragma, open its own transaction or leak a read transaction that blocks WAL checkpointing).
- `func Open(path string) (*Store, error)`: opens the writer with `SetMaxOpenConns(1)`, opens the reader with the same DSN plus `&_pragma=query_only(1)`, migrates the file (Task 1's `Migrate`), then reads `PRAGMA journal_mode` back and refuses a file that does not answer `wal` with a named error naming the path. On any error both pools are closed and no half-open handle is returned.
- The DSN, built here and nowhere else: `file:` + the escaped path + `_pragma=journal_mode(WAL)&_pragma=busy_timeout(5000)&_pragma=synchronous(NORMAL)&_pragma=foreign_keys(1)&_txlock=immediate`. `_txlock=immediate` is why every `BeginTx` in this package is a write-locked transaction; it is not a second locking mechanism.
- `func (s *Store) Close() error` closing both pools, and `func (s *Store) Path() string`.
- `schemaV1`, the DDL of exactly three tables and no fourth:
  `meta(key TEXT PRIMARY KEY, value TEXT NOT NULL)`; `saved_items(kind TEXT NOT NULL CHECK (kind IN ('bookmark','like')), post_id TEXT NOT NULL, sort_index TEXT NOT NULL, first_seen INTEGER NOT NULL, last_seen_at INTEGER NOT NULL, present INTEGER NOT NULL DEFAULT 1, json TEXT NOT NULL, PRIMARY KEY (kind, post_id))` with `CREATE INDEX saved_items_order ON saved_items(kind, present, sort_index DESC)`; `sync_runs(id INTEGER PRIMARY KEY, kind TEXT NOT NULL, full INTEGER NOT NULL, started_at INTEGER NOT NULL, finished_at INTEGER, pages INTEGER NOT NULL DEFAULT 0, items INTEGER NOT NULL DEFAULT 0, absent INTEGER NOT NULL DEFAULT 0, stop_reason TEXT NOT NULL DEFAULT '')`. There is no `accounts` table: one account per mirror is the decision, and the owner is a `meta` row.
- The declaration the allowlist test reads: `var declaredTables = map[string][]string{...}` naming each table and its columns in order, and `var declaredMetaKeys = []string{"schema_version", "owner", "last_success_bookmark", "last_success_like"}`. Task 3 asserts the file against these two values, so a column added later without a migration fails a test rather than a review.

`internal/store/migrate.go` — migrations as ordered data:
- `type migration struct { version int; ddl string }` and `var migrations = []migration{{version: 1, ddl: schemaV1}}`, ordered by version, appended to (never edited) when a later build adds one.
- `func Migrate(ctx context.Context, db *sql.DB) (int, error)`: reads the current version, refuses a file newer than `migrations[len(migrations)-1].version` with `ErrSchemaNewer` (a downgrade is not an upgrade), then applies every migration newer than the current one in version order and returns how many it applied — 1 on a fresh file, 0 on an already-migrated one, which is what makes idempotence assertable rather than inferred.
- `applyMigration`: one transaction per migration containing the DDL *and* the version row (`INSERT INTO meta(key, value) VALUES('schema_version', ?) ON CONFLICT(key) DO UPDATE SET value = excluded.value`), committed together. A crash between them is not a state the file can be left in. The version is not recorded in any SQLite pragma: the schema version lives in `meta` as the row `('schema_version', '<n>')`, and it is read back from that row (after `sqlite_master` is consulted for the table's existence, because reading `meta` on a never-migrated file is a "no such table" error rather than an empty result).
- `func schemaVersion(ctx context.Context, db *sql.DB) (int, error)` reporting -1 for a fresh file.

`internal/store/read.go` — the reader the pane will use:
- `const PageSize = 20` — the mirror's page size is the network page size (`internal/xsource`'s `homeCount`), so `position` means one thing on every list (06-UI-SPEC.md, `## Width Model`).
- `func (s *Store) Page(ctx context.Context, kind domain.SavedKind, c domain.Cursor) (domain.PostPage, error)`: reads `present = 1` rows of that kind, ordered `sort_index DESC`, keyed by the cursor (`sort_index < ?` when a cursor is given), limited to `PageSize`; decodes each row's `json` into a `domain.Post` through the private snapshot type; returns `Next` as the last row's `sort_index` when the page is full and older rows exist and empty otherwise; `Requested` is the number of rows the page carried; `FetchedAt` is the caller's instant taken from a package-level `var now = time.Now` so tests can freeze it. A cursor the store did not mint is not special-cased: it simply selects a suffix of the list, which is what an opaque cursor means.
- `func (s *Store) Status(ctx context.Context, kind domain.SavedKind) (domain.MirrorStatus, error)`: the owner and that kind's last success from `meta`, plus `SELECT count(*)` over `present = 1` and `present = 0` for the kind. Reads go through the reader pool and every statement is a query: nothing in this file writes.
- `read.go` and `sync.go` share the private snapshot type; put it in `sync.go` (the file that produces it) and let `read.go` consume it.

`internal/store/migrate_test.go` — ordered, idempotent, torn-proof:
- a fresh file reports 1 applied and version 1; a second `Migrate` reports 0 applied and leaves the version at 1 (idempotence as a value, not an absence of errors).
- a torn upgrade is impossible: the test's second migration carries a DDL that fails after its first statement; `Migrate` returns the error, the version stays 1, the rows are untouched, and no table from the failed migration exists.
