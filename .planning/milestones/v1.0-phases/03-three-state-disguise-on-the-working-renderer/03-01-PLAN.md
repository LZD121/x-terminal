<objective>
Put the whole disguise on the render side as values rather than code paths: extend the one Grammar the composer
already takes into the UI-SPEC's template/placement seam, add the deterministic alias function the covers'
identity slot projects, define the four cover grammars with their literals, and add the panic frame and the
covered copy and status line.

Purpose: the phase's central constraint is that a cover is a `Grammar` over the existing composer — a second
rendering path is a failure of the phase. Doing the pure half first is also what makes the privacy promise
provable by shape rather than by audit: the alias function lives in `internal/render`, and `internal/render`
cannot write.

Output: the extended `Grammar`/`Blocks`, `alias.go`, `cover.go`, `panic.go`, the covered `copy.go`/`status.go`,
and the unit tests that pin every literal rendering at 80 and 120 columns.

Requirement: DSGT-06, DSGT-07 and DSGT-09 are this plan's `requirements` entries.

Phase goal (ROADMAP, quoted): "The user can wear the feed as work-software output or replace the pane with a
one-key panic frame — identities aliased, nothing on screen naming the real product — and step back without
losing their place."
</objective>

**The panic frame** (`panic.go`, the UI-SPEC's `## The Panic Frame`). `func PanicFrame(w, h int) string`
returns a constant frame: it asks the model for nothing but its size. The literal is the 21 `ok <package>
<duration>` lines of a `go test ./...` run of the fictional `corp/...` monorepo, with the package column
starting at cell 8 and the duration column at cell 40 (the frame's own constants; the spacing is spaces only).
Rules, each one asserted:

- The frame owns rows 1..`H`: every row is exactly `W` cells, space-padded, and there is no status line. `H`
  rows of exactly `W` cells is the whole contract; the frame never pads a row to a second width.
- At `W` above the longest line the rows are **not** stretched: the same 21 lines, byte-identical at 120 as at
  80, each padded to `W`. A frame that filled 120 cells of text would read as a UI rather than as output.
- At `W` below the longest line the lines wrap with `text.Wrap` as a terminal wraps them; if the wrapped
  content is taller than `H`, the frame shows its last `H` rows and adds no truncation mark (the terminal
  scrolled).
- Below 60 columns the frame is the same one-line floor message the plain reader uses (`CopyPaneTooNarrow`),
  padded to `W` — the row count is still `H`.
- The frame contains **zero ESC bytes**, no feed text, no handle, no display name, no prompt, no hostname, no
  clock, no product noun: it makes no claim a colleague could contradict.
- The literals live in this file as named constants; `CopyTitlePanic` (`make`) and the plain reader's own
  title constant (`x-terminal`) are declared here too, because both are "the name of the thing on screen" —
  the shell and `internal/term` read them, and nothing else spells them.

**The covered copy** (`copy.go`). The UI-SPEC's `## Copywriting Contract` covered column, every string a
constant, plus the per-style list names of the covered-list table (`stream=in`/`stream=all`,
`branch=main`/`branch=next`, `queue=ci`/`queue=next`, `view=mine`/`view=all`) as a function of the style and
the feed, and the covered help-independent copy: `no records in this view`, `the read succeeded and found
nothing - press r to refresh`, `loading records...`, `loading older records`, `{n} new record`,
`{n} new records`, `no new records`, `no older records (cursor stalled)`. The lookup takes a `CoverStyle` and
a `domain.HomeKind` and returns the covered or the plain string, so the plain constants stay exactly where
Phase 2 put them and a caller cannot pick the wrong one by accident. Add the substitution: any string the
cover did not author — the classifier's pane sentence and any reachability detail — passes through one
function that replaces the literal host `x.com` and any `*.x.com` occurrence with `upstream`,
case-insensitively, and changes nothing else.

**The covered status line** (`status.go`). `StatusFields` gains `Cover CoverStyle` whose zero value is the
plain reader, and every covered difference is that field's:

- The two copy changes and only those two: the state word `no route to x.com` renders as
  `no route to upstream` (the remedy stays verbatim), and the classifier's own sentence and any detail string
  go through the substitution above. The remedy column is deliberately **not** re-voiced: it is the user's
  instruction and a remedy in the cover's vocabulary would be an instruction that does not work. This residue
  is a named compromise, not an oversight.
- The list field renders the style's own name for the same list, and because those names are longer, the
  covered line drops the droppable `list` field in more states at 80 columns. The field order, the drop rule
  and the never-dropped fields (`state`, `remedy`, `budget`) are Phase 2's, unchanged: the drop rule is the
  declared, tested mechanism for exactly this, and no covered name is shortened to dodge it.
- The budget line stays verbatim and is never dropped: an observer reads `200 requests, 12 rate-limited` as
  the covered tool's own rate limit, which is coherent with every cover.
- The notice and the empty and loading copy are the covered strings above; the state word and the remedy still
  come from the classifier, so a covered failure can never render as nothing and the classifier's vocabulary
  stays the only vocabulary for failure.
- With `Cover` left at its zero value the composition is Phase 2's, byte for byte (the golden frames check it).

**Tests** (`panic_test.go`, `status_test.go`): the panic frame's rows and cells at a table of sizes (60, 79,
80, 120, 200 × 24, plus `H` = 12 and 40), including the "shows its last H rows" and the floor branches; zero
ESC bytes; the absence of every feed string, handle, hostname and product noun (asserted against the fixture
corpus's own strings, so the check cannot pass vacuously); the constant-frame property (the same bytes at both
